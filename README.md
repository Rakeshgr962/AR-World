# AR World Builder Research Documentation 🌍

[![License](https://img.shields.io/github/license/Rakeshgr962/AR-World?style=flat-square)](LICENSE)

This repository contains the design drafts, project proposals, technical presentations, and demonstration media for **AR World Builder**—a spatial computing app allowing users to build and edit 3D layouts interactively.

---

## 📂 Included Artifacts
- `AR World Builder report.docx`: Detailed system architecture design.
- `technical.pptx` & `AR WORLD PPT.pptx`: Technical presentation files.
- `AR_World_Builder (1).mp4`: Captured video demonstration of spatial concepts.
